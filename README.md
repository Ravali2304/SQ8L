## 🎛️ What Is SQ8L?

SQ8L is a software instrument that recreates the sound and behavior of the Ensoniq SQ-80 synthesizer. The original SQ8L project by Siegfried Kullmann became well known among musicians who wanted the warm, distinctive character of the SQ-80 in a computer-based music setup. This repository continues that work as a 64-bit port for macOS and Windows.

The project is built around preservation. Instead of treating the classic synthesizer as something that only exists in old hardware, SQ8L makes its sound available on modern computers. That means you can use it with current music software while keeping the feel of the original instrument.

SQ8L is not a generic synth plugin. It is a focused emulation project. The goal is to keep the sound, response, and musical character of the SQ-80 available to people who create music today.
